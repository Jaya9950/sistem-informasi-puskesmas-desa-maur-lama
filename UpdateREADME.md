# Sistem Persediaan Obat Puskesmas

Sistem informasi berbasis web yang dikembangkan untuk membantu pengelolaan persediaan obat pada Puskesmas Pembantu Desa Maur Lama, Sumatera Selatan.

Project ini dikembangkan sebagai Academic Project dengan menggunakan framework Laravel dan database MySQL.

## Tentang Project

Sistem ini dirancang untuk membantu proses pengelolaan data obat dan persediaan secara lebih terstruktur.

Sistem menyediakan fitur untuk pencatatan stok, monitoring persediaan, serta pembuatan laporan sehingga proses pengelolaan obat dapat dilakukan secara lebih efektif.

## Fitur Utama

- Pengelolaan data obat
- Pencatatan stok masuk
- Pencatatan stok keluar
- Monitoring ketersediaan obat
- Pengelolaan database obat
- Pembuatan laporan persediaan
- Sistem informasi berbasis web

## Metode Pengembangan

Project ini dikembangkan menggunakan metode:

**Rapid Application Development (RAD)**

Metode RAD digunakan untuk mendukung proses pengembangan sistem secara iteratif melalui tahapan perencanaan kebutuhan, desain, pengembangan, dan pengujian.

## Struktur Sistem

Project dibangun menggunakan framework Laravel dengan struktur utama:

- `app/` — Logic aplikasi
- `database/` — Database, migration, dan seeder
- `public/` — Asset dan file publik
- `resources/` — View dan resource aplikasi
- `routes/` — Routing aplikasi
- `config/` — Konfigurasi aplikasi

## Tujuan Project

Project ini bertujuan untuk menghasilkan sistem informasi yang dapat membantu pengelolaan persediaan obat secara terstruktur dan mempermudah proses monitoring serta pelaporan.
